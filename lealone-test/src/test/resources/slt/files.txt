# Curated sqllogictest subset for the Lealone regression gate (see README.md).
#
# Paths are relative to -Dslt.dir (default /tmp/sqllogictest/test), i.e. the "test" directory of a
# gregrahn/sqllogictest checkout. The suite itself is NOT committed to this repository.
#
# Size: 45 files, ~377k queries, roughly 18 s single threaded on a laptop-class machine.
# The full 137 file set (select1-5, evidence/*, random/expr/*) is documented in README.md; this
# list is the subset that is fast enough and quiet enough to run on every change.
#
# select1-4: pre-generated queries against 3+ column, 1000 row tables with 5 indexes each,
# executed before and after CREATE INDEX (the file itself creates the indexes half way through).
# They exercise index scans, ranges, IN lists (single and multi table), ORDER BY, DISTINCT, UNION/
# EXCEPT/INTERSECT and up to 9-way joins - the richest plan coverage in the suite.
# select4 was the file that caught the broken IndexCursor change at 68e7a8744 (1,683 of 2,832
# queries returned too few rows); it is back in the list since 30c02350b and passes 2,832/2,832.
select1.test
select2.test
select3.test
select4.test

#
# evidence/*: documentation examples. Only files that Lealone can execute are kept here;
# slt_lang_createtrigger, slt_lang_reindex, slt_lang_replace, slt_lang_update, in1 etc. use
# SQLite/MySQL only DDL or TEXT-as-CLOB indexes and are excluded (see README.md).
evidence/in2.test
evidence/slt_lang_createview.test
evidence/slt_lang_dropview.test
