# H2风格的SQL脚本测试

`com.lealone.test.script.SqlScriptTest` 会递归遍历本目录，执行所有 `.sql` 文件，并把每个语句的
实际输出和脚本里写的期望输出逐行比较。新增脚本不需要改Java代码；但脚本必须全绿，只写当前
Lealone确实通过的语句。

## 脚本格式

每个SQL语句以 `;` 结尾，后面跟着以 `>` 开头的期望输出：

    select length('abc') c1;
    > C1
    > --
    > 3
    > rows: 1

- 查询结果的期望输出依次是: 列名行、`-` 分隔线、数据行、行数行
- `> rows: N` 无序比较N行，`> rows (ordered): N` 按顺序比较N行
- 只有一行一列时可以写 `>> value`
- 更新语句写 `> update count: N`；Lealone的DDL更新计数是0，所以DDL也写成 `update count: 0`
- 异常写 `> exception <数字错误码>`，不用H2的错误码名字(Lealone缺一部分名字)
- `--` 开头的行是注释，执行时跳过

## 约定

- 只收录当前Lealone通过的语句。已知和H2不同的地方，按Lealone的实际输出写期望值，并在语句
  前加一行 `-- LEALONE: 与H2不同，原因...`；无法解释的差异不收录
- 每个脚本用一个独立的内存embedded数据库(`jdbc:lealone:embed:`)，脚本自己建表、自己删表，
  不依赖TCP端口和外部数据
- 期望输出里的连续空格会被压缩成一个空格，值末尾的空格不参与比较

## 新增脚本

在任意子目录下新建 `.sql` 文件即可，`SqlScriptTest` 会自动发现。期望输出可以先用一个临时的
JDBC探针程序把语句跑一遍，把实际输出整理成上面的格式，再人工确认结果是否符合预期。
